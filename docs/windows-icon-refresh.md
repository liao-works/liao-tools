# Windows 桌面 / 任务栏图标更新排查

新图标在仓库中来自同一份 `src-tauri/icons/icon.ico`，经 Tauri 构建嵌入 Windows 可执行文件。网页 Logo 和侧边栏 Logo 的更新**不等于**已更新电脑上旧版本的 EXE、桌面快捷方式或任务栏固定项。

## 先检查安装版本

1. 完全退出所有 Liao Tools 窗口和 Todo 小组件（必要时在任务管理器确认 `liao-tools.exe` 已结束）。
2. 在开始菜单找到 Liao Tools，右键进入「打开文件位置」；若打开的是快捷方式，再右键它选择「属性」并查看「目标」。确认它指向预期安装目录，不是旧文件夹/手动复制的可执行文件。
3. 找到实际 `liao-tools.exe`，右键「属性 → 详细信息」查看产品/文件版本。更新为修复后的正式版本后应显示对应新版本。
4. 直接查看该 EXE 文件在资源管理器中的图标：若 EXE 仍显示旧图标，请从 [GitHub Releases](https://github.com/liao-works/liao-tools/releases) 重新下载最新 Windows x64 NSIS 安装包，关闭程序后安装；不要只复制前端资源。

## EXE 新、桌面快捷方式或任务栏仍旧

Windows 会保留旧固定项与图标缓存，特别是通过安装程序升级后。已知 Tauri 应用也有升级后固定任务栏图标未刷新问题。不要为了刷新图标删除用户数据目录。

1. 从任务栏上 **取消固定**旧的 Liao Tools。
2. 删除桌面上的**旧快捷方式（.lnk）**，不要删除软件本体或用户数据。
3. 在「开始」菜单中找到**新版本** Liao Tools，使用它重新「固定到任务栏」；如需桌面快捷方式，使用新版本的开始菜单快捷方式重新创建。
4. 仍显示旧图时，可重启 Windows 资源管理器（任务管理器 → Windows 资源管理器 → 重新启动），必要时注销后重新登录。

## 如何区分问题来源

- **可执行文件也显示旧图**：可能安装的是旧版、目标路径指向旧 exe、构建未正确嵌入新 ICO，或系统对 exe 图标仍有缓存。
- **EXE 是新图但桌面/任务栏旧图**：优先清理旧 .lnk/任务栏固定项并重新固定。
- **任务栏运行窗口是旧图但 EXE 是新图**：排查 Tauri 窗口原生图标；应用启动时应明确调用 `set_icon`，Todo 独立窗口也应同步。
- **左侧导航为新图**：仅证明前端资源已更新，不能单凭它判断 Windows 原生图标已更新。

本指南不建议批量删除系统图标缓存数据库，也不建议删除应用设置或业务数据。
