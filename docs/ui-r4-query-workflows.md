# R4 第二阶段：Tax / Alta 查询工作区

依赖 R4 工作台基础分支 \`ui/redesign-r4-foundation\`，本 PR 仅包含查询交互和真实状态呈现，不改写 Rust/业务规则。

## 已完成

- **税率单码**：精确查询、模糊候选列表和选码后再精确查询。GB/NI 各自展示税率、核验状态、来源版本与核验时间。
- **税率证据**：弹窗查看两地区原始来源；一键网页临时比对继续调用原命令，明确不修改正式库。
- **Alta 单码**：4/6/8/完整匹配；结果区明确区分“命中当前清单”、“当前清单未命中”、查询错误和本地数据库为空。
- **例外证据**：显示原始限制/例外文本，避免从文字中的编码片段自动断言豁免。
- **批量文案**：Alta 的 \`safe\` 显示为“未命中”，不表述为“全面合规”；税率批量进度避免总量为零除法。
- **错误处理**：查询错误不再显示为“无结果”；本地数据检测失败不再伪装成“数据库为空”。

## 输入校验边界

只做必须的 HS 编码结构检查：
- 输入可包含空格、连字符，提交时归一化为数字，不自动补零。
- 关税精确查询必须 10 位；模糊查找 4–10 位；Alta 按用户选定的匹配位数或 4–10 位。
- 不额外要求用户手工确认查询、不做重复联网检测，也不拦截合法的特殊税率文本。

## 验证重点

- TypeScript + Vite build。
- Tax 精确结果 GB/NI 不同 status（verified、conditional、stale、pending、legacy），无数据和异常。
- 模糊列表不直接呈现税率，选码触发 \`tax_exact_search\`。
- 输入变化/切换模式时旧结果失效；后到达的旧请求结果不覆盖新输入。
- Alta 命中、有例外、未命中、数据库为空与网络/命令异常。
- 既有批量 Excel、数据更新、历史入口不回归。

本次 CI 检查只证明前端构建；正式 Tauri 数据库联调与 Windows/macOS 手工回归仍需执行。
