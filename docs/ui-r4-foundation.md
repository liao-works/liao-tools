# R4 UI 第一阶段：工作台与应用骨架

此分支将 R4 高保真原型中**可独立迁移的基础 UI** 接到现有 React/Tauri 应用。不会迁移 HTML demo 里的模拟税率、价格、文件处理计时器或 localStorage 演示数据。

## 本次实现

- 将根路由由系统工具重定向改为工作台；所有旧工具路由保持不变。
- 工作台提供分组任务入口、中文及业务别名过滤，不引入虚构统计。
- 单一导航配置用于首页、侧栏和全局命令面板，避免工具名称不一致。
- Ctrl/Cmd + K 打开全局命令面板，可筛选、方向键选择、Enter 跳转、Esc 关闭。
- 侧栏按工作空间、业务查询、文件处理、效率工具、管理分组。
- 小窗口侧栏采用抽屉形式，桌面仍可折叠。保留更新检测、主题选择、设置与 Todo 小组件原路由。
- 新增可选陶土橙主题，保留旧主题及持久化 ID，不改变现有用户默认主题。

## 本次不包含

- R4 原型中模拟的业务数据和文件处理步骤。
- 正式数据管理的新路由。现有 Tax/Alta 数据页面仍沿用原路径。
- 对 Tax、Alta、Excel、UPS/DPD、RevCal、Todo 等业务 API 和 Rust command 的改写。
- OS 级全局快捷键；Ctrl/Cmd + K 仅在应用窗口内生效。
