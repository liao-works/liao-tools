# R4 UI 第三阶段：本地文件处理任务闭环

基于 \`ui/redesign-r4-query-workflows\` 的堆叠变更，保持现有 Tauri 业务命令和输出语义不变。

## 实现内容

- **Excel 拆分**：海铁有图、海铁无图、空运三种模式；本地 \`.xlsx\` 选取；读取真实 \`get_excel_config\`，再执行 \`process_excel_file\`。模式切换不再无意义地清空已经选择的同类文件。
- **UPS/DPD**：两套模板类型，必填主文件、可选明细表；执行 \`process_ups_dpd_file\`。模式切换保留文件，用户可以移除或更换单个输入。
- **结果反馈**：统一成功、失败和运行中视图。成功展示实际输出文件名/路径及“打开文件”“复制路径”；失败保留输入和错误信息，方便直接重试；日志按需展开。
- **模板设置**：分别显示 UPS/DPD 的实际保存状态，可选择自定义本地 \`.xlsx\`，或恢复内置模板。后端负责模板的实质验证，不叠加一次没有必要的前置校验。
- **Excel 高级配置**：保留现有独立配置面板，修复“自动保存”不实表述以及配置读取失败后一直显示加载的问题。

## 不会实现的虚假行为

目前文件处理命令仅在结束时返回 \`success/output_path/message/logs\`；没有可用于展示真实细粒度完成百分比的稳定进度事件。本阶段使用不定量的处理中状态，**没有添加任何模拟百分比、虚假倒计时或文件上传流程**。日志来自实际处理结果，不生成模拟日志。

## 验收

1. \`pnpm install --frozen-lockfile && pnpm build\`。
2. 选择文件后切换模式，文件不丢失、旧结果清除；开始处理时不能重复提交任务。
3. Excel 三模式分别调用现有配置与处理命令，失败保留文件，成功能打开和复制真实输出路径。
4. UPS/DPD 主文件必填、明细可选；无明细时请求传 \`undefined\`；切换模板不会清空主数据。
5. 后端返回 \`success=false\` 和命令抛异常时分别显示真实错误，不能误报成功。
6. 模板配置显示真实模式和路径，取消选取不改动原状态，重置后重新读取实际保存配置。
7. Windows/macOS 桌面端真实文件处理、文件打开、窄窗口、日志滚动手动回归。

仅通过前端 CI 不意味着已完成真实 Tauri 端到端验证。
