# R4 第四阶段：Amazon、系统工具、Todo

以第三阶段分支 \`ui/redesign-r4-file-workflows\` 为基础，统一效率工具的 R4 UI 与真实结果状态，不改写现有 Tauri 业务命令。

## Amazon 商品

- 保留现有 16 个站点和 \`revcal_search\` / \`revcal_batch_search\` / Excel 读取、导出命令。
- 站点在查询前选择；切换站点清空之前站点的结果、异常与导出路径，避免跨国家价格误判；运行中不允许并行另一个查询。
- 保留后端 \`revcal-batch-progress\` 真实进度，不生成估计或假百分比。
- 结果显示查询站点、成功、未找到和失败数量；明确使用产品提供的货币单位。
- Excel 成功导出后展示真实保存路径和打开入口；打开文件失败不再倒写为“导出失败”。
- 缺少商品 URL 时显示 ASIN 原文，不渲染指向 \`#\` 的假链接。

## 系统工具

- 保留后端 \`get_all_tools\` / \`get_system_tools\`、\`launch_system_tool\` / \`launch_custom_tool\`。
- 支持加载失败重试和真正的工具列表/管理切换，自定义工具添加、编辑、启用、禁用、删除、排序继续用原命令。
- 修复旧编辑表单中的自定义 ID（\`custom_N\` 转数字）与保存时无条件设为启用的问题。
- 工具卡片只用可键盘聚焦的按钮启动；热键忽略输入框、按钮和对话框，避免误触。
- 最近使用使用 \`get_recent_programs\` 显示只读历史。原界面调用 \`record_program_launch\` 不是真正的执行命令，不能伪装成“启动成功”。
