# 英国 / 北爱尔兰关税查询

这个功能用来查询中国原产商品进入英国（GB）与北爱尔兰（XI）的进口税率：本地离线库中的普通第三国税率、反倾销 / 反补贴附加税与官方条件税率，并能在这些税率基础上估算关税成本。页面分五个页签：「单码查询」「成本试算」「批量 Excel 查询」「数据更新与审核」「数据统计」。第一次使用前，需要先在「数据更新与审核」页签下载本地税率数据库。

## 在哪里找到入口

- 侧边栏「业务查询」分组 →「关税查询」。
- 工作台首页的「关税查询」卡片；「常用操作」里的「批量税率查询」会直接打开「批量 Excel 查询」页签，「本地数据」面板右上角的「数据维护」链接会打开「数据更新与审核」页签。
- 顶部搜索框（Ctrl K）输入「关税」「税率」等关键词也能直达；命令面板只匹配固定的工具名称与关键词，输入具体编码数字（如 8507600090）搜不到。
- 页签支持 URL 直达：`/tax`（默认「单码查询」）、`/tax?tab=calc`、`/tax?tab=batch`、`/tax?tab=update`、`/tax?tab=stats`。

## 逐步操作

### 单码查询：查一个商品编码的税率

1. 打开页面后默认停在「单码查询」页签。若本地还没有税率数据，页面顶部会出现「数据库为空」提示卡，点其中的「前往数据更新 →」先下载数据。
2. 在「输入商品编码 HS Code」输入框中输入 10 位编码（例如 0101210000）。编码只能包含数字、空格和连字符（如 `8507 6000 90` 会自动去掉空格），应用不会自动补齐位数；输入后输入框右侧会出现「清空编码」按钮。
3. 「查询方式」保持默认的「精确」，点击「开始查询」（或按 Enter）。按钮变为「查询中…」，随后显示查询结果。
4. 精确查询返回一条记录时，页面显示「查询结果 · 编码」卡片：上方是六张税率卡——「英国 (GB) 进口税率」「北爱尔兰 (NI) 进口税率」「反倾销 · 英国 GB」「反补贴 · 英国 GB」「反倾销 · 北爱 XI」「反补贴 · 北爱 XI」；下方「商品与税率详情」面板列出商品编码、商品描述、两地的普通第三国税率和最后记录日期，右上角的「复制编码」可复制编码。

![单码查询精确结果：8507600090 的英国与北爱进口税率卡，以及反倾销、反补贴税率卡（截图为演示数据）](/images/tax/tax-single-result.png)

5. 税率显示「—」表示本地暂无可显示的普通税率，不表示 0%；税率卡下方的提示文字也说明了这一点。若记录带有条件税率或历史数据标识，结果上方会出现「本地税率存在明确标识的条件或历史数据，使用前请核对相关来源。」提醒。
6. 继续往下是几块补充信息（有数据才显示）：「条件税率与其他官方措施」列出官方条件税率、特殊用途等措施——只有可确定的无条件普通税率才会进入上面的默认税率卡；「中国原产 · 反倾销和反补贴措施」按措施列出附加税表达式、附加代码、适用条件与生效状态，若本地库提供了企业对应税率，会先显示「企业／出口商对应税率」表格，措施卡里的「查看官方法规」可打开对应法规页面；右侧「来源与核验」面板显示英国与北爱两个来源的版本、核验时间，点「打开来源页面」在浏览器中打开官方税率页。
7. 想与官方网页核对时，在「商品与税率详情」底部点击「网页临时比对（不修改数据库）」。比对期间页面底部出现「正在比对商品 ×××」进度条，右下角弹出「比对日志」窗口逐条滚动日志；完成后弹窗告知比对结果，本地数据不会被修改。若先勾选旁边的「比对后把差异写入本地数据库」，按钮会变成「更新并写入本地数据库」，比对发现的差异会写入本地库——这属于手动修改，下次官方数据快照更新时会被覆盖。
8. 不确定完整编码时，把「查询方式」切到「模糊」，输入 4–10 位编码再点「开始查询」。结果以表格列出所有相似编码，列为商品编码、英国税率、北爱尔兰税率、反倾销（GB）、反补贴（GB）、反倾销（XI）、反补贴（XI）、相似度、操作；英国税率、北爱尔兰税率、反倾销（GB）、反补贴（GB）旁有复制按钮，「操作」列的图标分别是「打开英国税率网址」「打开北爱尔兰税率网址」（记录中有北爱链接时显示）和「网页临时比对（不修改本地数据）」。模糊结果仅供选码，不代表税率相同，选定后建议切回「精确」确认。
9. 没有匹配记录时，页面显示「没有匹配的本地税率记录」，并提示尝试另一种查询模式。

### 成本试算：估算一票货的关税与 VAT

1. 切到「成本试算」页签。上方「单码试算」表单默认按目的地英国 GB、币种 GBP、汇率 1、进口 VAT 20% 计算，「中国原产（计入反倾销 / 反补贴）」默认勾选。
2. 填写「商品编码（10 位）」和「货值」（标签随币种显示，如「货值（GBP）」），按需修改「目的地」（英国 GB / 北爱尔兰 XI）、「计税数量（可选）」「币种」（GBP / USD / CNY / EUR）、「汇率（1 币种 = ? GBP）」「运费」「保险费」。选 GBP 时汇率固定为 1、输入框不可改；运费与保险费会计入完税价值（CIF）。
3. 税率表达式含按量计税时（如 £15.60/100kg）必须填「计税数量」，单位与表达式一致——500kg 填 5。「进口 VAT（%）」默认 20（英国标准税率），可以修改。
4. 点击「开始试算」。下方出现「试算结果 · 编码（英国 / 北爱尔兰）」卡片：先列出黄色警告（如有）；「税费构成」表格逐行显示税费构成、官方表达式、金额（GBP）与说明，无法解析的税率行显示「无法试算」，不会按 0 计算；底部汇总「关税合计（GBP）」（含有效关税率）、「进口 VAT（GBP）」（计税基础为完税价值 + 关税）、「税费合计（GBP）」（含综合税率）与「试算状态」（「完整」或「部分完成」）。试算未包含消费税（烟酒等）、优惠协定税率与条件税率，结果仅供参考，申报前请核对官方页面。
5. 同页签下方的「批量 Excel 试算」可一次试算多个编码：点击「下载模板」，在保存对话框中选择位置，得到「关税成本试算模板.xlsx」（模板列为商品编码、货值、运费、保险费、计税数量），下载完成后弹窗询问「是否立即打开编辑」。
6. 点击「选择文件」选择填好的 Excel（.xlsx 或 .xls），文件名会显示在按钮旁；目的地、中国原产、币种、汇率、VAT 沿用上方表单的当前设置。
7. 点击「开始批量试算」，进度条走完后显示总数 / 成功 / 失败统计和「错误详情」（最多列出 10 条），并弹窗询问是否查看结果文件。

### 批量 Excel 查询：按表格批量查税率

1. 切到「批量 Excel 查询」页签。第一步卡片「下载Excel模板」：点击「下载模板」，保存「税率查询模板.xlsx」并按格式填写商品编码，下载完成后弹窗询问「是否立即打开编辑」。
2. 第二步卡片「选择本地文件并处理」：点击「选择文件」，选择 .xlsx 或 .xls 文件，下方显示「已选择: 文件名」。
3. 点击「开始批量查询」，按钮变为「处理中...」并显示进度条。完成后「处理结果」卡片显示总数 / 成功 / 失败与错误详情，并弹窗询问是否查看结果文件。

### 数据更新与审核：保持本地税率库最新

1. 切到「数据更新与审核」页签。页面显示「本地版本」卡（版本号、记录数、更新日期）；点击「检查更新」后会出现「远程版本」卡，标注「🎉 有可用更新」或「✅ 已是最新版本」。
2. 发现新版本时「立即更新」按钮可用，点击后显示下载进度（百分比与已下载 / 总大小）。离线或获取失败时页面会提示「当前无法获取远程版本。本地数据仍可查询，但无法确认是不是最新税率。」
3. 点击「更新历史」可打开历史窗口，查看逐字段的税率变化明细。
4. 页面下方的「数据更新日志」自动记录本机最近 50 条检查 / 下载 / 安装 / 失败事件，右侧按钮可刷新。
5. 「审核与影子预览（高级操作 · 不写入正式税率库）」折叠区面向数据审核，日常查询用不到：在「NI Other · 证据审核」加载审核报告 JSON，查看 NI Other 的人工复核清单（每条可「核对官方页面」）；在「第三国税率 · 独立预览」导入影子预览 ZIP 后，输入 10 位编码点「查询预览」，对比当前生产数据库与官方 GB 目标税率预览。
6. 部分应用构建还会在折叠区内显示「签名审计包验证（非生产）」卡片（仅当构建时内置了 Ed25519 信任公钥）：点「选择签名审计 ZIP 进行验证」，用内置公钥核验发行方身份与数据完整性；即使验证成功，也不会安装到正式税率数据库。折叠区内的所有操作都不会写入正式税率库。

### 数据统计：看本地库覆盖了多少编码

1. 切到「数据统计」页签，统计自动加载，右上角「刷新」可重新读取。
2. 「数据总览」显示数据版本、发布时间、库文件大小、商品编码总数（并校验与本地库行数是否一致）以及英国、北爱的来源版本日期。
3. 「普通第三国税率覆盖」用两条覆盖率条显示英国 GB 与北爱尔兰 XI「有唯一、无条件官方默认税率」的编码占比；空白表示官方本身没有默认税率，不是 0%。
4. 「条件税率与官方选项」显示条件性选项、未解析选项等规模，对应查询页的「条件税率与其他官方措施」区块；「中国原产贸易救济（反倾销 / 反补贴）」分英国 GB、北爱尔兰 XI 两组列出涉及反倾销 / 反补贴的编码数与措施行数。
5. 「无默认税率编码的原因分布」列出官方原因及数量，例如「GB：官方无第三国关税措施」「GB：仅授权用途/附加代码条件税率」等。

## 小技巧

- 成本试算使用非 GBP 币种时，需要在「汇率」里自己填「1 币种 = ? GBP」，可以先在[汇率查询](/guide/exchange)里查好再填。
- 编码不确定就先用「模糊」圈定候选，再切「精确」看完整税率卡。
- 输入编码时带空格或连字符没问题，应用会自动去掉；但位数不对会直接提示，不会自动补齐或截断。
- 常用页签可直达：`/tax?tab=calc`、`/tax?tab=batch`、`/tax?tab=update`、`/tax?tab=stats`。

## 常见问题

**问：税率显示「—」是什么意思？**

答：表示本地记录中没有可显示的普通第三国税率，不表示 0%。具体原因可在「数据统计」页签的「无默认税率编码的原因分布」中查看。

**问：点击「开始查询」提示编码无效？**

答：精确查询需要 10 位数字编码，模糊查询支持 4–10 位；编码只能包含数字、空格和连字符，应用不会自动补齐位数。

**问：试算结果里有的行显示「无法试算」？**

答：该行税率无法按当前输入计算（例如条件税率，或按量计税没有填计税数量）。应用不会把它按 0 计算，「试算状态」会显示「部分完成」。

**问：各个页签都提示数据库为空？**

答：第一次使用需要先下载税率数据：到「数据更新与审核」页签点「检查更新」，发现新版本后再点「立即更新」。

**问：「网页临时比对」会改动本地数据吗？**

答：不会，比对结果只作提示。只有勾选「比对后把差异写入本地数据库」再执行比对才会写入；写入值属于手动修改，下次官方数据快照更新时会被覆盖。
