# 船司查询

收录 137 家船司的官网与货物跟踪入口；输入提单号、集装箱号或快递单号后，会自动识别单号类型与承运商，直达对应的官方查询页。适合两种场景：想找某家船司的官网或跟踪页，以及手里有一个单号但不知道该去哪家船司查。

## 在哪里找到入口

- 打开应用后，点击左侧边栏「业务查询」分组中的「船司查询」。
- 也可以在工作台点击「船司查询」卡片（卡片说明为「船司官网与货物跟踪入口」）。

页面分为「船司名录」和「货物追踪」两个页签，打开时默认显示「船司名录」。

## 逐步操作

### 在「船司名录」中查找船司

![船司查询页的「船司名录」页签：顶部搜索框、A–Z 首字母筛选和船司卡片](/images/shipping/01-overview.png)

1. 如果知道船司的代码或名称，直接在顶部搜索框输入，例如 `MSK`、`马士基` 或 `maersk`，列表会即时过滤。搜索不区分大小写，匹配范围是船司代码、中文名和英文名；输入内容后搜索框右侧会出现 × 按钮，点击即清空搜索。
2. 只记得首字母时，点击搜索框下方的字母按钮（A–Z）按首字母筛选；再点一次同一个字母即取消筛选，点「全部」恢复完整列表。
3. 字母按钮下方的一行小字实时显示结果数量（如「共 137 家船司」），选中字母时还会追加「· 首字母 X」。
4. 每家船司一张卡片，上面是船司名称、代码徽章（如 `ONE`）和英文全称。点「官网」会在系统浏览器中打开船司官方网站，点「货物追踪」打开该船司的货物跟踪页。
5. 搜索或筛选没有结果时，列表区域会提示「没有匹配的船司，换个关键词试试」。

少数船司的官网或跟踪链接在数据整理时已确认失效（如新东船务、FREESEAS、卡塔尔航运），对应按钮会置灰、不可点击。

### 在「货物追踪」中识别单号

1. 切换到「货物追踪」页签，在输入框中粘贴单号——提单号、集装箱号或快递单号都可以，例如 `COSU1234567890`。输入框右侧的 × 按钮可清空单号。
2. 输入后页面立即出现一张识别卡：徽章标注单号类型和规范化后的单号（自动去掉空格和连字符、转为大写）。例如上面的示例会显示「海运提单（中远海运）」。识别完全在本地完成，不联网也能出结果。
3. 若本地识别出了承运商，卡片会显示「本地识别：中远海运」和代码徽章 `COSCO`。
4. 根据单号类型，识别卡下方出现不同的按钮：
   - 海运提单或集装箱号且识别到船司：点「打开××官方跟踪页」（××为船司名），在浏览器中打开该船司的货物跟踪页。
   - 快递单号（如 1Z 开头的 UPS 单号、CN 结尾的 EMS 单号）：点「去运单轨迹查询（UPS）」这类按钮，会跳转到应用内「运单轨迹」页并自动填入该单号。
   - 无论什么单号都有「5688 识别并查询」，点击后在浏览器打开 5688.cn 的货物追踪结果页，由其在线识别承运商并跳转官方查询页。
   - 非快递单号还会出现「在运单轨迹中查询」，同样跳转应用内「运单轨迹」页并带上该单号。
5. 输入停顿约 0.7 秒后，页面会自动向 5688 发起在线识别，卡片标题「在线识别（5688）」旁出现转动的加载图标。
6. 在线识别成功后，卡片列出 5688 返回的承运商：代码徽章、中英文名和置信度（如「置信 98%」），每条带「官方查询页」按钮，点击即打开对应承运商的查询页；若 5688 系统内已有该单号的轨迹，还会列出「物流巴巴系统内轨迹（N 条）」，每条包含时间、地点和事件描述。
7. 在线识别失败或服务不可用时，卡片提示「在线识别暂不可用（原因），已回退本地识别与跳转方案」，此时上面第 4 步的按钮仍然可用。

单号前缀未命中内置船司表时，识别卡会提示（例如）「箱主代码 XXXX 未命中内置船司前缀，等待在线识别，或在下方名录中手动查找」；完全无法识别类型时，提示「未识别出单号类型，可在运单轨迹工具中批量查询，或由 5688 尝试识别」。

页面底部标注了船司数据的来源：「物流巴巴 · 船公司大全」（2026-10-19 收录），点击该链接可在浏览器打开源页。

## 小技巧

- 集装箱号、提单号里的空格和连字符可以照原样粘贴，识别前会自动去掉并转为大写，不影响结果。
- 只记得船司英文名的一部分也能搜，例如输入 `safmarine` 会同时命中「南非航运」（SAFMARINE）和代码为 SCL 的 Safmarine 条目。
- 快递单号建议直接去「运单轨迹」批量查询；「货物追踪」页签更适合海运提单号和集装箱号。
- 5688 在线识别需要联网；断网时本地识别和「打开××官方跟踪页」的跳转不受影响，只是少了在线识别卡的内容。

## 常见问题

**问：识别卡显示「未识别」怎么办？**

答：说明单号不符合常见的提单、集装箱、快递和空运单格式。可以点「5688 识别并查询」交给在线识别兜底，或点「在运单轨迹中查询」用 17TRACK 尝试。

**问：快递单号为什么没有「打开官方跟踪页」按钮？**

答：快递单号统一交给运单轨迹（17TRACK）查询，所以按钮是「去运单轨迹查询（承运商）」，点击后跳转到应用内「运单轨迹」页。首次使用需要在该页填入 17TRACK 的 API Key。

**问：某家船司的「官网」「货物追踪」按钮是灰的？**

答：该船司的源站链接已失效，数据整理时被置空，按钮因此不可点击。可以尝试在名录中搜索同集团的其他船司代码。

**问：识别出了集装箱号，但没有显示承运商？**

答：本地识别依赖内置的箱主代码前缀表（收录主流船司），未命中的前缀会提示等待 5688 在线识别，也可以到「船司名录」页签搜索该船司后手动点「货物追踪」。

## 相关功能
