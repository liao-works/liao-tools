# 体积 / 计费重计算

国际物流的运费常按「计费重」收取——取实重与体积重（抛重）中较大的一个。本页按包裹的长宽高计算 CBM（立方米）、体积重与计费重，并给出 20GP / 40GP / 40HQ / 45HQ 常用柜型的装柜数量估算。全部计算在本地完成，不需要联网。

## 在哪里找到入口

- 左侧边栏「业务查询」分组中的「体积 / 计费重」；
- 工作台（首页）的「体积 / 计费重」卡片；
- 按 Ctrl K 打开顶部搜索框，输入「cbm」或「体积」也可直达。

页面从上到下分为四块：「计费参数」「包裹明细」「装柜试算（单规格）」「批量 Excel 试算」。

![体积 / 计费重计算页面总览：计费参数、包裹明细与装柜试算（单规格）](/images/cbm/01-overview.png)

## 逐步操作

### 计算一批包裹的计费重

1. 先在「计费参数」的「计费模式」下拉中选择计费系数：默认「空运（1:6000）」，另有「国际快递（1:5000）」「海运拼箱（1:1000）」；选「自定义系数」时旁边会出现「系数（cm³/kg）」输入框（默认 6000），按货代给的系数填写。
2. 「尺寸单位」下拉按货物实际单位选择（cm / m / mm / in / ft），「重量单位」选择（kg / g / lb）。这两个单位对整个页面生效，包括下方的装柜试算与批量试算。
3. 在「包裹明细」第一行依次填写：名称（占位提示「名称 1（可选）」，可以不填）、长、宽、高、件数、实重。同一行的长宽高指**单件**尺寸；同规格有多件，直接改件数即可（件数默认已填 1），实重填单件重量。
4. 货物有不同规格时，点「添加一行」继续填；某行不要了，点行尾的垃圾桶按钮删除该行，删到最后一行时页面会自动补一行空行。
5. 点「开始计算」，按钮短暂变为「计算中…」，下方出现「计算结果」卡片。

![计算结果示例：纸箱 A 120×80×60 cm 单件 45 kg，空运 1:6000 时计费重 96 kg 按体积重计费](/images/cbm/02-calc-result.png)

6. 结果卡顶部标注本次使用的系数（如「系数 1:6,000（空运（1:6000））」），并有四张数值卡：总体积（m³）、总实重、体积重、计费重；计费重卡下方标注「按实重计费」或「按体积重计费」。以截图为例：120×80×60 cm 的纸箱 1 件、实重 45 kg，按 1:6000 算得体积重 96 kg，大于实重，因此计费重取 96 kg。
7. 四张卡下方是逐行明细表，列出每行的尺寸（换算成 cm）、件数、总体积、总实重、体积重、计费重与计费方式；名称留空的行以「第 N 行」标记。
8. 再往下是「柜型估算（参考值）」表：对 20GP / 40GP / 40HQ / 45HQ 四种柜型，分别给出内尺寸、容积、参考载重，以及按体积、按重各需几柜；「建议柜数」取两者中较大的值。表中容积与载重是行业常用约数，未考虑装箱排版损失，实际以船公司与运输路线限重为准。
9. 之后只要修改计费模式、单位、系数或任何明细，结果会自动清空，改完再点一次「开始计算」即可。

### 装柜试算（单规格）

同一个商品装整柜时，可以用这一块估算需要几个柜：

1. 填写单件的长、宽、高（沿用上方「计费参数」里的尺寸单位）、总件数；「单件实重」可留空，留空时只按体积估算。
2. 「可堆叠」复选框默认勾选，按堆叠层数计算；货物不能受压时取消勾选，只装一层。
3. 点「装柜试算」，表格列出每种柜型的「每柜可装」「需柜数」「体积利用率」「重量利用率」与「限制因素」（体积或重量）。当某柜型连一件都装不下时——单件按体积摆不进内尺寸，或单件实重超过该柜型的参考载重——该行的「每柜可装」会显示「超出柜型」、需柜数显示「—」。
4. 结果上方有一行汇总：单件体积、单件重量（填了实重时）与合计体积。这是地面摆放 × 堆叠层数的简化估算，不含混装与复杂 3D 排柜，实际装载请以排柜方案为准。

### 批量 Excel 试算

包裹行数多时，可以用 Excel 一次算完：

1. 点「下载模板」，在弹出的保存对话框里选好位置（默认文件名「体积计费重模板.xlsx」）；保存后会弹出「模板下载完成」对话框，点「打开文件」可直接打开编辑，也可以点「复制路径」记下位置。
2. 模板共六列：名称（可选）、长、宽、高、件数、实重，并自带两行示例与说明文字。删掉示例后照列填写；件数留空按 1 件，实重留空按 0。
3. 点「选择文件」，在文件对话框中选填好的 .xlsx 或 .xls，按钮旁会显示「已选择：文件名」。
4. 批量试算沿用页面顶部「计费参数」中的尺寸单位、重量单位与系数，开始前先确认它们与表格数据一致。
5. 点「开始批量试算」（未选文件时按钮为灰色不可点），试算期间显示进度条和百分比；完成后提示「试算完成 成功 X 行，失败 Y 行」，页面列出总数 / 成功 / 失败三个数字，失败行较多时在「错误详情」中列出原因（最多 10 条）。
6. 同时会弹出「批量试算完成」对话框，点「打开文件」查看结果。结果文件与输入文件在同一目录，文件名为「原文件名_计费重试算_时间.xlsx」，含两个工作表：「试算结果」逐行列出行号、尺寸、体积、计费重等，失败行在「备注」列写明原因；「试算汇总」给出合计与柜型估算。

## 小技巧

- 海运拼箱按 1:1000 计费，1 m³ 货物的体积重正好是 1000 kg，绝大多数情况下会按体积重计费。
- 实重不确定时可以先留空，只算体积和体积重；实重留空按 0 处理，不会报错。
- 换了计费模式或单位后，已显示的结果会自动清空——这是有意设计，避免旧结果和新参数混淆。
- 「柜型估算」看的是总量，适合报价前快速估柜；要精细排某个柜，用「装柜试算（单规格）」。
- 名称列只用于识别行，不参与计算；留空时明细表自动用「第 N 行」标记。

## 常见问题

**问：点「开始计算」提示「请至少填写一行尺寸数据」？**

答：长、宽、高**全部留空**的行会被自动忽略，当每一行都被忽略时就弹出这条提示。注意填 0 不算留空：填了 0（或负数）的行仍会提交计算，由后端判为无效——若还有其他有效行，会在结果区顶部的黄色警告里提示「长、宽、高必须大于 0」；若所有行都无效，则弹出「试算失败」提示。

**问：计算结果顶部出现黄色警告条？**

答：说明有部分行的数据不合法（如尺寸 ≤ 0、件数 ≤ 0、实重为负数）。无效行不参与合计，其余行照常计算；按警告里的行号提示修正后重新点「开始计算」。

**问：装柜试算里显示「超出柜型」？**

答：表示这种柜型每柜连一件都装不下，两种情况会触发：单件按体积摆不进（长、宽方向超出内尺寸），或单件实重超过该柜型的参考载重。可以看其他更大柜型的结果，或考虑分拆包装、减轻单件重量。超过柜内高度但地面能摆下的件不算超出，只是按只装一层计。

**问：批量试算后「失败」不为 0？**

答：打开结果文件的「试算结果」工作表，看失败行「备注」列的具体原因，最常见的是长宽高不是数字或小于等于 0。修正原表后重新批量试算。

**问：「建议柜数」是怎么算出来的？**

答：分别用总体积 ÷ 柜型容积、总实重 ÷ 参考载重向上取整，取较大值。柜型容积与载重是行业约数，未考虑装箱排版损失，实际以船公司与运输路线限重为准。
