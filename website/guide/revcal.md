# Amazon 商品查询

按站点查询 Amazon 商品的尺寸、重量、价格与商品信息（类目、销售排名、评论数、评分），支持单个编码查询、多行批量查询（可从 Excel 导入），结果可导出为 Excel。数据来自第三方公开接口，价格与详情请以 Amazon 来源页面为准。适合发货前核对商品尺寸重量、批量采集竞品信息等场景。

## 在哪里找到入口

打开应用后，点击左侧边栏「业务查询」分组中的「Amazon 商品查询」；也可以在工作台首页点击「Amazon 商品查询」卡片进入。

页面从上到下依次是：站点选择、单码查询、批量查询、结果展示与导出选项、查询结果。

![Amazon 商品查询页面：站点选择、单码查询、批量查询与结果区](/images/revcal/01-overview.png)

## 逐步操作

### 1. 选择查询站点

1. 在页面顶部「选择 Amazon 查询站点」下拉中选择目标站点，可选 Amazon GB / DE / FR / IT / ES / IN / AE / TR / SA / NL / SE / PL / EG / BE / ZA / IE，共 16 个站点，默认 Amazon GB。
2. 切换站点会清空当前结果、筛选和进度，避免混用不同国家的数据。
3. 查询进行中时下拉不可用，需等当前查询结束。

### 2. 单码查询

1. 在「单码查询」卡片输入框中输入 ASIN / UPC / EAN / ISBN 或商品关键词，然后点击「查询」按钮（或直接按回车）。
2. 查询期间按钮显示加载动画；结果出现在下方「查询结果」表格中，每命中一个商品占一行（关键词查询可能返回多个商品）。
3. 没有找到商品时会弹出「未找到商品」提示；查询失败会弹出「查询失败」提示，失败原因同时显示在结果行的「错误信息」列。

![单码查询 B0D1234567 的结果：统计卡显示查询 1、命中 1，结果行含尺寸与价格（截图为演示数据）](/images/revcal/02-single-query.png)

### 3. 批量查询

1. 在「批量查询」卡片的文本框中输入编码，每行一个。提交时会自动去掉空白行并去重，查询完成后会提示「已去除 N 个重复」。
2. 编码较多时，也可以点击「上传 Excel」按钮，选择一个 .xlsx 文件：程序读取第一个工作表第一列的编码（第一行按表头跳过）并填入文本框，弹出提示显示读取到的编码数量。若第一列没有读到内容，会提示「未读取到编码：请确认第一列从第二行开始填写查询码」。
3. 点击「开始批量查询」，程序逐条查询（约 1 条/秒），文本框下方出现进度条和「当前条数/总数：编码」的进度说明；首趟结束后会对失败的编码自动补查一轮，补查中的进度行会带「补查」字样。
4. 全部完成后弹出「批量查询完成」提示，写明成功与未找到/失败的条数，结果整体替换到「查询结果」表格。

批量查询期间，「查询」「开始批量查询」按钮和站点下拉都不可用，避免请求交叉。

### 4. 筛选、排序结果

1. 「查询结果」上方的四张统计卡分别显示：查询编码、命中编码、未找到或失败、商品结果。
2. 在筛选框输入内容，可按查询码、ASIN 或商品名称过滤行；勾选「只看失败」只保留未找到或查询失败的行。筛选生效时会显示「显示 X / Y 行」。
3. 点击「查询码」或「Prix」（即价格列）表头可排序，再次点击在升序/降序间切换，表头文字会带 ↑ / ↓ 标记；没有价格的行在按价格排序时始终排在最后。

### 5. 查看商品详情

1. 点击结果行末的「详情」按钮，打开「商品信息详情」弹窗。
2. 弹窗内显示商品图片、名称、ASIN、品牌，以及价格（含币种）、尺寸、重量（含单位）、类目、销售排名、评论数、评分；接口未提供的字段显示「未提供」。
3. 点击表格中的 ASIN 编号或弹窗中的「在 Amazon 查看」链接，可打开该商品在 Amazon 的页面核对。

### 6. 导出 Excel

1. 如需把尺寸拆成独立数值列，先勾选「结果展示与导出」中的「分列展示和导出长 / 宽 / 高 / 重量」复选框：结果表格的尺寸列会随之拆为「长」「宽」「高」「重量」四列，导出文件同样按长/宽/高/尺寸单位/重量/重量单位分列。不勾选时，尺寸以「Dimensions du produit」一列的合并格式展示和导出。
2. 点击「查询结果」右上角的「导出 Excel」按钮，在弹出的保存对话框中选择位置（默认文件名为 `Amazon商品查询_站点代码_日期时间.xlsx`）。
3. 导出成功后会弹出提示并显示保存路径，同时自动打开导出的文件。
4. 「清空」按钮可一键清空当前全部结果；没有结果时「清空」与「导出 Excel」均为灰色不可点。

## 小技巧

- 单码查询支持直接粘贴商品关键词，但用 ASIN / EAN / UPC 等编码查询更精准。
- 批量查询遇到接口限流时会自动放慢节奏，整体耗时会变长，属正常现象；失败的编码不必手动重查，程序会自动补查一轮。
- 批量结束后想复查失败项：勾选「只看失败」，把剩下的失败码复制出来，换个时间段再批量查一次。

## 常见问题

**问：查询提示「未找到商品」怎么办？**

答：先确认编码拼写正确；再用编码代替关键词重试。不同站点的在售商品不同，也可以切换到其他站点再查。

**问：批量查询比较慢是正常的吗？**

答：是。程序按约 1 条/秒的节奏逐条请求，触发接口限流时还会自动加大间隔并重试。编码多时请耐心等待，查询期间按钮会保持禁用。

**问：表格里的「Dimensions du produit」「Prix」是什么意思？**

答：分别是「商品尺寸」和「价格」，为与查询来源接口的原始列名保持一致，界面保留了原文。
