# Todo 清单

记录与整理日常待办：每条任务可带优先级和到期日，列表按「待办 / 已完成 / 全部」筛选。还可以把清单以独立小窗口（桌面小部件）放到桌面上常驻，与主窗口实时同步，配合全局快捷键随手记一笔。

## 在哪里找到入口

- 打开应用后，点击左侧边栏「效率工具」分组中的「Todo 清单」。
- 也可以在工作台点击「Todo 清单」卡片（卡片说明为「记录与整理待办任务」）。
- 工作台右栏有一块「待办日历」面板，与本页共用同一份数据，点右上角的「管理待办」即可跳到本页。
- 在任何应用里按下全局快捷键「快速添加任务」（默认 Ctrl + Alt + N），会直接打开 Todo 页并把光标放进输入框（小组件窗口开着时则唤起小组件的输入框）。

## 逐步操作

### 添加一条任务

1. 在顶部「添加新任务...」输入框中输入任务内容。
2. 在右侧下拉框中选择优先级：「低 / 中 / 高」，默认「中」。优先级决定任务圆圈和「低 / 中 / 高」徽标的颜色（低为绿、中为黄、高为红）。
3. 需要到期日时，点击优先级右侧的日期按钮（默认选中今天，按钮上显示如「10/24」），弹出一张月历：点某一天即选中并收起弹层，也可点「今天」「明天」快捷项；左右箭头可翻月；不需要时点「清除」去掉到期日。
4. 点击「+」按钮（或直接按 Enter）添加。新任务出现在列表顶部，归入「今天」分组，输入框清空并可继续输入下一条。

列表按任务的创建日期分组，分组标题显示「今天」「昨天」或具体日期（如 `2026-10-22`），越新越靠上。某个筛选下没有任务时会显示对应提示，如「当前没有待办任务」。

### 勾选与筛选

1. 点击任务左侧的圆圈，任务变为绿色对勾、标题划线、整行变淡，计入「已完成」；再点一次恢复为待办。
2. 页面标题下方的「N 待办 · N 已完成」始终统计全部任务，不受当前筛选影响。
3. 在「待办 / 已完成 / 全部」三个筛选标签中切换，当前标签高亮显示。

### 修改与删除任务

1. 任务行右侧常显三个按钮：「设置到期日」（日历图标）、「编辑任务」（铅笔图标）、「删除任务」（垃圾桶图标）；桌面宽度下它们平时呈半透明，鼠标悬停或点入行内时变为清晰可点。
2. 点「设置到期日」打开与添加行相同的月历弹层，选好立即保存；在弹层里点「清除」则取消该任务的到期日。
3. 点「编辑任务」或直接双击任务标题进入编辑：Enter 或点击输入框外保存，Esc 取消；把内容清空再保存等同于放弃修改。
4. 点「删除任务」立即删除该条任务，没有确认弹窗。
5. 到期日已经过了今天（早于今天）仍未完成的任务，到期徽标会变红并显示「M/d 已过期」（如今天已是 10 月 24 日，一条 10 月 20 日到期的任务会显示「10/20 已过期」）；当天或以后到期的仍显示蓝色「M/d 到期」，当天到期不算过期。

### 清除已完成

任务全部处理完后，列表底部会出现「清除已完成 (n)」按钮，点击一次删除所有已完成任务；没有已完成任务时该按钮不显示。

### 用键盘操作

1. 按 ↑ / ↓ 在任务之间移动，选中项高亮并带「当前选择」标记；再按 Enter 勾选或取消这条任务。注意：焦点还在顶部输入框时（比如刚按 Enter 添加完一条，输入框已清空但仍保持焦点），按 Enter 不会勾选任何任务——此时 Enter 只用于添加，先点击页面空白处移开焦点，再用 Enter 勾选。
2. 光标在顶部输入框且已输入文字时，Enter 的作用是添加任务，↑ / ↓ 也留给文本光标，不会误勾选；输入框为空时按 ↑ / ↓ 同样可以选择任务。
3. 双击任务标题进入编辑，同上一节。

### 打开桌面小部件

1. 点击右上角「桌面小部件」按钮，会弹出一个独立的小窗口（默认 360×460，浮动显示、不透明），可以一直摆在桌面上。

![桌面小部件窗口：标题栏左侧显示「Todo 清单 (3)」，右侧是「嵌入桌面」「置顶」「最小化」「关闭」，下方是添加行与带数量的筛选标签](/images/todo/02-widget.png)

2. 按住标题栏空白处拖动，可把小窗口移到任意位置；位置和大小会被记住，下次打开还在原处。
3. 标题栏右侧从左到右四个按钮：「嵌入桌面」「置顶」「最小化」「关闭」。
4. 「嵌入桌面」把小部件贴到桌面层，像桌面便签一样垫在普通窗口下面；按钮随之变为「退出桌面嵌入」，再点一次恢复浮动窗口。
5. 「置顶」让小窗口始终浮在其他程序前面；再次点击「取消置顶」。嵌入与置顶互斥：开启其中一个会自动关闭另一个。
6. 「最小化」收起窗口到任务栏；「关闭」同样只是收起窗口，任务数据保留，回到主窗口再点「桌面小部件」即可重新打开。

### 小部件里的日常操作

- 小部件内有同样的添加行：「添加新任务...」输入框 + 优先级下拉 + 「+」按钮（小部件内不提供到期日）。
- 筛选标签带数量：「待办 (n)」「已完成 (n)」「全部 (n)」，默认选中「待办」。
- 任务行操作与主窗口一致：点圆圈勾选、双击改名，悬停时显示优先级徽标和「编辑任务」「删除任务」按钮。
- 两边实时同步：在主窗口或小部件任一边增删改，另一边立即更新，因为它们读写的是同一份本地数据。

### 调整 Todo 设置

1. 点击主页面右上角的齿轮按钮，打开「Todo 设置」窗口。
2. 「外观」区说明：桌面小部件跟随应用主题与深浅色模式，在「偏好设置」中调整后实时联动。
3. 「桌面小部件」区：「透明度」滑杆（50%–100%）、「窗口宽度」（200–600px）与「窗口高度」（200–800px）数字框，改动即时生效并保存。注意透明度只在「嵌入桌面」模式下生效，浮动窗口始终不透明。
4. 「快捷键」区列出三项：「切换显示」「置顶/取消置顶」「快速添加任务」，默认分别为 Ctrl + Alt + T、Ctrl + Alt + P、Ctrl + Alt + N（macOS 上为 Cmd + Alt + …）。
5. 点某项右侧的铅笔图标（或按键框本身），框内显示「按下快捷键...」时直接按下组合键即完成录制；Backspace / Delete 清空，Esc 取消；主按键支持字母、数字和 F1–F12，且至少要带一个修饰键。
6. 两项快捷键设成相同组合时会红字提示冲突，此时无法保存；确认无误后点「保存快捷键」生效，「恢复默认」可一键还原，最后点右下角「完成」关闭窗口。

三个快捷键都是全局的，应用在后台也能触发：「切换显示」显示或隐藏小组件窗口（未打开时则打开）；「置顶/取消置顶」切换小组件的置顶状态；「快速添加任务」在小组件开着时唤起小组件并聚焦输入框（自动切到「待办」筛选），否则打开主窗口的 Todo 页并聚焦添加框。

## 小技巧

- 不想给任务带到期日时，先把日期按钮点开、在弹层里点「清除」，再输入内容添加；用小部件添加的任务本身就不带到期日。
- 连续录入多条任务时不用碰鼠标：输入完按 Enter，输入框清空后接着输入下一条即可。
- 工作台右栏的「待办日历」把带到期日的任务以圆点和条数标在月历上，悬停可预览当天任务，也能直接勾选、删除或按选中日期新增，适合按天安排。
- 快捷键设得太顺手容易和其他软件冲突；按下没反应时，到「Todo 设置 → 快捷键」换一组不常用的组合。

## 常见问题

**问：误删的任务能找回吗？**

答：不能。「删除任务」和「清除已完成 (n)」都是立即生效、没有确认弹窗，清理前先确认列表里没有还要留着的条目。

**问：调了「透明度」小部件外观没变化？**

答：透明度只在「嵌入桌面」模式下生效，浮动窗口始终不透明。先在小组件标题栏点「嵌入桌面」，再看效果。

**问：主窗口和小部件的数据会不同步吗？**

答：两边读写同一份本地数据，任何一边的改动都会实时推送到另一边。万一保存时提示「待办数据已在其他窗口更新」，主窗口会自动改用最新数据，红色提示条点 × 即可关闭；「同步最新数据」按钮则在小部件的错误条上，点它可手动拉取最新数据。

**问：设置里改的快捷键保存不了？**

答：检查两项：组合键里至少要有一个修饰键（Ctrl / Alt / Shift 等），且主按键只能是字母、数字或 F1–F12；与其他快捷键重复时页面会红字提示，改成不同组合即可。
