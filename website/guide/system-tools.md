# 系统工具

「系统工具」是一个快速启动器：应用内置了一批常用系统程序，可以直接一键启动；也可以把自己电脑上的其他程序添加进来，配上描述和快捷键。内置系统工具与自定义工具分开管理，内置工具只能启动，不能被修改或删除。

## 在哪里找到入口

打开应用后，点击左侧边栏「效率工具」分组中的「系统工具」。也可以按 `Ctrl K` 唤出顶部全局搜索，输入「系统工具」后直达本页。

进入页面后，顶部是标题卡，其下右上角有三个按钮：

- 「添加工具」：直接打开新增自定义工具的对话框。

## 逐步操作

### 启动一个内置工具

Windows 下内置了计算器、记事本、画图、任务管理器、系统设置、文件资源管理器等工具。

1. 在「工具列表」视图中浏览工具卡片，卡片上显示工具图标、名称、描述和分类标签。
2. 点击卡片上的「启动工具」按钮，对应的程序会在应用外以自己的窗口打开。
3. 启动成功后页面右下角会弹出提示「启动命令已执行」；如果程序未能启动（例如程序已被卸载或路径失效），会弹出「启动失败」并显示原因。

设置了快捷键的工具，卡片底部会以键帽样式显示这个快捷键。

### 用搜索和分类筛选工具

1. 在搜索框（占位文字「搜索名称或描述」）中输入关键词，卡片列表会即时过滤，匹配范围包括工具的名称、描述和内部标识。
2. 点击搜索框右侧的分类按钮「全部 / 系统 / 实用 / 开发 / 媒体 / 自定义」，列表只显示所选分类下的工具；点「全部」恢复完整列表。
3. 搜索或筛选没有结果时，页面会显示「没有符合搜索条件的工具」。

### 添加自定义工具

1. 点击右上角「添加工具」按钮，弹出标题为「添加工具」的对话框。
2. 填写「工具名称」（必填）和「描述」。
3. 在「程序路径」（必填）一栏填入要启动的程序路径，也可以用两个选路径按钮代替手输：
   - 点「浏览文件」会打开文件选择窗口（筛选可执行文件 .exe / .bat / .cmd / .app / .sh），选中后路径自动填入；如果「工具名称」还空着，会按文件名自动补上。
   - 点「已安装程序」会打开「选择已安装的程序」对话框，列出本机已安装的软件，顶部搜索框（占位文字「搜索应用程序...」）可按名称过滤，底部显示「找到 N 个应用程序」；点选某一项后，名称、路径、图标和描述（如「由 ×× 开发」）会自动填好。
4. 按需填写「命令参数（可选）」（多个参数用空格分隔）和「工作目录（可选）」（可点「浏览」选择目录）。
5. 在「分类」下拉中选择「系统 / 实用 / 开发 / 媒体 / 自定义」，默认「自定义」。注意：分类选「自定义」时，工具卡片上的分类徽章会显示英文 "custom"，其余四个分类显示对应中文。
6. 在「快捷键（可选）」中填写组合键，格式如 `Ctrl+Alt+1`。
7. 点击「保存」，提示「工具已保存」，新工具随即出现在工具列表中。「保存」按钮在「工具名称」和「程序路径」都填好之前不可点击。

### 编辑、排序、启停与删除（管理工具视图）

1. 点击右上角「管理工具」按钮，切换到「工具管理」列表，页面提示「拖拽卡片可以调整工具顺序」。
2. 按住每行开头的拖拽手柄上下拖动，松开后顺序即被保存。
3. 自定义工具的行尾有三个操作按钮：「禁用 / 启用」（电源图标）、「编辑」、「删除」。被禁用的工具会带「已禁用」徽章，在工具列表里卡片变暗、按钮显示为「当前不可用」。
4. 点「编辑」会打开「编辑工具」对话框，表单与「添加工具」相同且已填入当前内容，改完点「保存」即可。
5. 点「删除」会弹出确认框「删除自定义工具"××"？」，确认后该工具被移除并提示「工具已删除」。

内置工具的行上只有拖拽手柄，没有上述操作按钮——内置工具不能被编辑、禁用或删除。

### 用快捷键启动

1. 给工具配置好快捷键（添加或编辑对话框中的「快捷键」一栏）。
2. 回到「工具列表」视图，当焦点不在输入框、下拉框或按钮上、也没有对话框打开时，直接按下工具设定的组合键即可启动该工具。
3. Windows 内置工具也预置了部分快捷键，例如计算器 `Ctrl+Alt+C`、记事本 `Ctrl+Alt+N`。其中 `Win+I`、`Ctrl+Shift+Esc` 这类组合键同时是 Windows 的系统级快捷键，通常由操作系统优先响应。

## 小技巧

- 「最近使用」区域只显示真实执行过的启动记录（目前自定义工具的启动会写入记录，内置工具的启动不会），最多显示 5 条；没有记录时整个区域不出现。把鼠标悬停在徽章上可以看到程序的完整路径。
- 添加工具时优先用「已安装程序」按钮选路径：它会把名称、图标、描述一并填好，省去手动输入。
- 给最常用的两三个工具设快捷键即可，组合键冲突或过多反而记不住。

## 常见问题

**问：点「启动工具」提示「启动失败」怎么办？**

答：先确认程序本身还能正常运行——自定义工具检查「程序路径」指向的文件是否还在原位置（程序升级或卸载后路径容易失效）；内置工具检查对应的系统程序是否可用。修正路径后重新启动即可。

**问：为什么内置工具没有「编辑」按钮？**

答：内置系统工具与自定义工具是分开管理的，内置工具只能原样启动；「编辑」「删除」「禁用/启用」只对自定义工具开放。想调整内置工具的行为，可以新建一个指向同一程序的自定义工具。

**问：按了快捷键工具没启动？**

答：页面快捷键只在焦点不在输入框、文本域、下拉框或按钮上时生效，而且对话框打开时不响应；先点一下页面空白处再按。另外 `Win+I`、`Ctrl+Shift+Esc` 这类系统级组合键可能被 Windows 优先接管，建议给自定义工具选 `Ctrl+Alt+字母/数字` 这类不冲突的组合。
