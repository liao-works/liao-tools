# Alta 禁运商品查询

输入 HS Code，与本地保存的 Alta 禁运清单做匹配，判断某个商品编码是否命中禁运条目。支持三种用法：在「单码检查」逐个核对编码，在「批量筛查」用 Excel 一次过一遍清单，在「禁运数据维护」更新本地禁运数据。查询本身读取本地数据库；只有更新清单时才访问数据源。

## 在哪里找到入口

- 打开应用后，点击左侧边栏「业务查询」分组中的「Alta 禁运查询」。
- 也可以在工作台点击「Alta 禁运查询」卡片进入；「常用操作」区的「批量禁运筛查」会直接打开批量筛查页签。
- 页面地址支持 `?tab=` 参数直达：`/alta?tab=batch` 打开「批量筛查」，`/alta?tab=manage` 打开「禁运数据维护」；不带参数时默认停在「单码检查」。

页面顶部是「单码检查」「批量筛查」「禁运数据维护」三个页签，下面分别说明。

## 逐步操作

### 单码检查：核对一个 HS Code

1. 在「商品编码（HS Code）」输入框中输入要检查的编码，例如 `8507600090`。输入框只接受数字（空格和连字符会被自动忽略）；输入内容后右侧会出现 × 按钮，点击可一键清空。
2. 在「匹配位数」下拉中选择匹配方式，默认「6 位匹配」，可选「4 位匹配」「6 位匹配」「8 位匹配」「完整编码」。4 / 6 / 8 位匹配按编码前几位与清单比对，「完整编码」要求整条编码与清单条目完全一致；位数越短，能命中的条目范围越宽。
3. 点击「检查禁运」按钮（在输入框中按回车键等效）。查询完成后，下方出现「查询结果」卡片。

结果卡片会给出三种判定之一：

- **命中禁运条目**：至少存在一条匹配的限制记录。下方「匹配项」表逐条列出编码、描述、匹配级别和例外，含例外的条目会把例外编码单独标出。
- **当前数据库未命中**：当前匹配位数下没有匹配到禁运条目。这只说明本机这份清单没有查到对应记录，不代表货物全面合规或允许出口。
- **编码无效**：提交的编码不满足要求，需要修正后重新检查。

![单码检查命中状态：查询 8507600090 后显示「命中禁运条目」横幅，匹配级别 6 位、匹配条目 2 项](/images/alta/02-single-check.png)

### 批量筛查：用 Excel 一次检查一批编码

1. 不确定文件格式时，先点击「下载模板」。系统弹出保存对话框，默认文件名 `Alta查询模板.xlsx`；保存后会弹出「模板下载完成」对话框，可选择「打开文件」立即编辑，或「复制路径」留待之后处理。模板只有一个工作表，表头为 `HS Code`，把要查的编码逐行填在这一列即可。
2. 已有现成 Excel 文件的话，直接进行下一步——程序会自动识别表头中含「HS」「Code」「海关」「编码」等字样的列作为编码列，不要求列名完全一致。
3. 点击「选择文件」，在弹出的对话框中选择 `.xlsx` 或 `.xls` 文件。选中后文件名和完整路径会显示在卡片中，按钮变为「更换」，右侧出现 × 可移除已选文件。
4. 在「匹配位数」一排选项中点选「4位匹配」「6位匹配」「8位匹配」或「完全匹配」，默认「6位匹配」。（注意批量页的选项文案与单码页略有差别：这里是「完全匹配」。）
5. 点击「开始批量筛查」，按钮显示为「正在检查本地数据…」。完成后出现「批量筛查完成」卡片，显示「总条数 / 命中禁运 / 未命中 / 无效编码」四项统计，同时弹出「Alta 禁运查询完成」对话框，可点「打开文件」查看结果，或「复制路径」；之后也可点结果卡片中的「查看结果」再次打开该对话框。

结果文件与原文件在同一目录，文件名为 `原文件名_禁运标记.xlsx`，包含 `HS Code` 和 `禁运状态` 两列：命中条目的编码和状态以红底标出并写「禁运」，未命中写「正常」，无法识别的编码写明原因（如 `编码长度不足6位`）。

### 禁运数据维护：更新本地清单

1. 切到「禁运数据维护」页签，页面会自动读取并显示「本地记录数」「最后更新」「数据库大小」。如果记录数为 0，会显示一条黄色提示：在获得清单前，不能把查询未命中理解为没有限制。
2. 点击「更新禁运清单」从 Alta 数据源拉取最新清单并重建本地数据库。更新期间按钮显示「正在更新清单」；更新任务在后台执行，切换到其他页面不会中断，回到本页即可看到结果，完成后本地统计自动刷新。
3. 点击「刷新本地状态」可重新读取记录数等统计信息。
4. 点击「更新历史」查看本功能的历次更新记录。
5. 进行过更新操作后，页面下方会出现「本次操作日志 · N 条」折叠面板，点击展开可看到本次更新的逐条日志。

## 小技巧

- 先宽后窄：用「4 位匹配」做宽口径初筛，再用「6 位匹配」「8 位匹配」或「完整编码」收窄，结合「匹配项」表里的例外信息逐条确认。
- 遇到「数据库为空」提示时，提示框里有一个「去更新」按钮，点击可直接跳到「禁运数据维护」页签，更新完成后再回来查询。
- 批量筛查前，可先拿文件里的一个编码到「单码检查」试一下，确认编码位数与匹配位数设置能对上。
- 「更新禁运清单」需要联网访问数据源；单码检查和批量筛查都只在本地数据库上执行，处理过程不依赖网络。

## 常见问题

**问：提示「请输入至少 6 位、最多 10 位的数字编码。」怎么办？**

答：输入的编码位数少于所选匹配位数。把「匹配位数」换成更小的值（如「4 位匹配」），或补全编码后重试。选「完整编码」时要求 4–10 位数字。

**问：提示「数据库为空」怎么办？**

答：本地还没有禁运清单。到「禁运数据维护」页签点击「更新禁运清单」，完成后再回来查询。清单为空时，查询未命中没有任何意义。

**问：「当前数据库未命中」是不是代表可以出口？**

答：不是。未命中只说明当前这份清单在当前匹配位数下没有对应记录。页面上的原话是「未命中不等于全面合规」——涉及实际申报时，请再核对官方来源与例外条款。

**问：「匹配项」表里的「例外」列是什么意思？**

答：部分禁运条目带例外条件。这一列会把例外编码单独标出；只显示「含例外」时，说明该条目有例外但清单里没有给出具体编码，需要核对原始条目。

**问：批量筛查报「未找到'HS Code'列」怎么办？**

答：程序靠第一行表头识别编码列，表头需包含「HS」「Code」「海关」「编码」等字样。按这个规则改一下表头，或改用「下载模板」生成的标准模板。
