# 汇率查询

汇率查询把常用货币双向换算、对人民币的参考汇率表和人民币中间价放在一页：给客户报美元价、核算日元成本时可以随手换算成人民币，也能查中国外汇交易中心发布的官方中间价做记账参考。汇率数据每日更新，离线时自动改用最近一次联网保存的缓存汇率，并在页面上明确提示。

## 在哪里找到入口

- 打开应用后，点击左侧边栏「业务查询」分组里的「汇率查询」。
- 也可以按 Ctrl K 调出全局搜索，输入「汇率」后回车直达；工作台「快速开始 · 常用工具」里也有「汇率查询」卡片。

## 逐步操作

### 认识页面布局

页面从上到下依次是：数据状态行、「货币换算」卡、「常用币种对人民币汇率」表和「人民币中间价」卡。

![汇率查询页面总览：顶部数据状态行、「货币换算」卡与「常用币种对人民币汇率」表（图中为离线演示数据，顶部的「已离线使用缓存汇率」提示是页面真实的离线降级逻辑）](/images/exchange/01-overview.png)

### 查看数据日期与来源，手动刷新

1. 看页面顶部的状态行：「数据日期 2026-10-23」是数据源的实际报价日，「来源」显示本次数据来自哪里，可能是 ExchangeRate-API、欧央行 ECB 或 Currency API 之一。
2. 点击状态行右侧的「刷新」按钮，重新获取汇率：刷新期间按钮图标会旋转并暂时不可点。应用对当天的数据有本地缓存，同一天内点击「刷新」会直接复用当天的缓存、不重复联网；跨天后再点才会真正联网取新数据。
3. 若数据日期早于今天，状态行会出现带警示图标的橙色提示「已离线使用 2026-10-23 的缓存汇率」（日期随实际缓存变化），表示当前用的是最近一次联网保存的汇率。

### 货币换算

1. 在「货币换算」卡的金额输入框输入金额（占位文字「金额」，默认 100），结果会随输入即时更新。
2. 点金额右侧的第一个下拉选择源币种，点「交换币种」按钮（双向箭头图标）右侧的下拉选择目标币种。选项格式如「USD · 美元」，共收录人民币加 30 种常用币种。
3. 结果区用大字显示换算结果，例如「100 美元 ≈ 711.74 人民币」，下方一行小字同时给出双向汇率：「1 USD = 7.1174 CNY · 1 CNY = 0.1405 USD」。
4. 点击中间的「交换币种」按钮，源币种与目标币种互换，换算方向随之反转（金额保持不变）。
5. 如果金额框被清空或填了非数字内容，结果区会显示「请输入有效金额」，改回数字即恢复。

### 查常用币种对人民币的汇率

1. 在「常用币种对人民币汇率」表中查看行情，四列分别是「币种」（代码 + 中文名称）、「单位」、「兑人民币」、「人民币兑」。
2. 「单位」列标明计价单位：美元等多数币种按 1 计，日元、韩元、越南盾、印尼盾按 100 计。「兑人民币」是 1 个显示单位的外币值多少人民币，「人民币兑」是它的倒数——1 人民币值多少个显示单位（如 7.1174 与 0.1405）。
3. 点击表格中的任意一行，该币种会填入上方换算器作为源币种，目标币种自动设为人民币；接着改一下金额即可得到换算结果。

### 查人民币中间价

1. 页面底部的「人民币中间价」卡以卡片格展示中国外汇交易中心发布的中间价，标题旁注明所属日期，例如「2026-10-23 · 中国外汇交易中心」。
2. 每张小卡片是一种货币的中间价，上面是中文名称、下面是四位小数的数值，依次为：美元、欧元、100 日元、港币、英镑、澳大利亚元、加拿大元、新加坡元、瑞士法郎、新西兰元。
3. 中间价获取失败时，卡片位置会显示原因，例如「中间价暂时无法获取：接口未返回发布记录（可能触发限流或当日尚未发布）。上方汇率表为市场参考汇率，可正常使用。」，并附「重试」按钮；点击「重试」会重新获取。

## 小技巧

- 点击汇率表任意行填入换算器后，目标币种固定是人民币；想换算成第三国货币，再点右侧下拉改一下目标即可。
- 中间价由中国外汇交易中心每日发布，常作为记账与核算的官方参考；上方汇率表来自第三方市场数据源，两者数值会略有差异。实际结汇、购汇请以银行牌价为准。
- 换算结果的小数位按数值大小自动调整：常规汇率显示 4 位，超过 100 的大数值显示 2 位，极小面值币种保留更多位。
- 需要频繁换算时，记住「点表行 → 改金额」这条路径，比每次手动选两个币种快。

## 常见问题

**问：提示「已离线使用 ×× 的缓存汇率」怎么办？**

答：说明当前展示的是缓存数据。应用每天首次打开时联网获取一次当天汇率并保存在本地，当天内再次打开或点「刷新」都用这份缓存；如果三个数据源暂时都连不上，就回退到最近一次成功的缓存并这样提示。换算功能不受影响，恢复联网后点「刷新」即可更新到最新数据。

**问：状态行里的「来源」为什么每次可能不一样？**

答：应用按 ExchangeRate-API → 欧央行 ECB → Currency API 的顺序尝试获取，哪个成功就用哪个，状态行显示的是实际成功的那一个。

**问：「人民币中间价」一直显示无法获取？**

答：中间价主源（中国外汇交易中心官网接口）对高频访问有限流，应用会自动改用国家外汇管理局的备用源；两者连续失败后会进入约 5 分钟的等待窗口，期间点「重试」可能仍提示「接口暂时不可用，正在等待重试窗口」，过几分钟再试即可。另外周末、节假日或当日中间价尚未发布时也会获取失败，此时上方汇率表仍可正常换算。

**问：换算区一直显示「请输入有效金额」？**

答：金额输入框被清空或含有非数字字符时会出现这个提示。输入框只接受数字（支持小数），填回数字即恢复显示。

**问：打开页面时一直转圈，或显示错误信息？**

答：首次加载会显示「正在获取汇率…」。如果本机从未成功联网获取过汇率且当前处于离线状态，页面会显示「无法获取汇率数据，请检查网络后重试。」和「重试」按钮，联网后点击即可加载。
