# 偏好设置

偏好设置集中管理 Liao Tools 的外观（显示模式与配色方案）、应用自身的更新选项，以及版本信息。想换一套界面颜色、关掉启动时的更新检查，或者确认当前用的哪个版本，都在这里。

## 在哪里找到入口

- 侧边栏最底部「管理」分组中点击「偏好设置」。
- 顶栏右上角的圆形头像按钮（悬停会提示「偏好设置」），点击同样进入。
- 按 `Ctrl K` 打开命令面板，输入「偏好设置」回车。

页面地址为 `/settings`，可以直接跳转。

## 逐步操作

### 更换显示模式

1. 进入「偏好设置」页，第一张卡片是「外观」，卡片说明写着「外观设置会在应用内立即生效」。
2. 在「显示模式」一行的右侧有一个下拉框，点开后有三个选项：「跟随系统」「浅色」「深色」。默认是「跟随系统」，即随操作系统的深浅色设置自动变化。
3. 选择「浅色」或「深色」后界面立即切换，选择会被记住，下次启动仍然生效；选「跟随系统」时，系统切换深浅色，应用也会跟着变。
4. 这里的选择会同步到应用的其他窗口（如桌面小组件），不会出现一边深色一边浅色。

![偏好设置页面：「显示模式」下拉当前为「跟随系统」，下方是 8 张配色方案主题卡，当前选中「暖陶橙 · PR3」](/images/settings/01-overview.png)

### 更换配色方案

1. 「外观」卡片内的下半部分是「配色方案」，说明为「选择主题色，不改变业务查询结果」——换主题只影响界面颜色，查询结果不受影响。
2. 共有 8 张主题卡，每张显示一个颜色方块、名称和描述：暖陶橙 · PR3（设计稿指定的暖陶橙主题）、默认蓝（经典的蓝色主题）、蓝色海洋（清新的海洋蓝）、紫色夜晚（神秘的紫罗兰）、绿色森林（自然的翠绿色）、玫瑰金（优雅的玫瑰金）、石板灰（专业的灰色调）、陶土橙 · R4（轻量暖色工作台）。
3. 点击任意一张卡片，界面主题色立即切换；当前选中的卡片会带主题色边框，右上角显示对勾。

### 管理应用自身的更新选项

1. 第二张卡片是「应用更新」，卡片说明明确写了它的管辖范围：「这里管理 Liao Tools 应用程序自身的更新检查，不控制英国/北爱关税或 Alta 数据库更新」。
2. 「自动检查应用更新」开关打开时，应用启动时会按已保存的间隔检查是否有新版本；不会自动安装。若说明文字后附有「当前检查间隔：N 小时」，表示检查间隔为 N 小时。
3. 点击这个开关会立即保存，无需其他确认操作；如果保存或读取失败，卡片内会出现红色错误提示（读取失败时还会出现「重试读取」按钮，点击后重新加载设置）。
4. 想手动查一次新版本，点击「检查应用版本」按钮，会弹出「检查更新」对话框并自动开始检查。
5. 检查结果在对话框中显示：
   - 已是最新版本时，提示「您使用的已是最新版本」。
   - 有新版本时，显示「发现新版本！」，并列出当前版本、最新版本、发布时间、文件大小和「更新说明」，点击「立即更新」开始下载，界面会显示下载进度；下载完成后按钮变为「安装更新」，点击后启动系统安装程序，按提示完成安装即可（期间对话框不能关闭）。
   - 检查失败时，对话框内出现错误提示，并附「打开官方版本下载页」按钮，可前往 GitHub Releases 手动下载。
6. 对话框底部还有一个「启动时自动检查更新（每24小时）」复选框，与页面上的「自动检查应用更新」开关是同一份设置，改哪边都行。对话框右下角的「重新检查」可以再查一次，「关闭」退出对话框。
7. 无论在页面还是对话框里发现新版本，侧边栏「应用更新」入口都会出现绿点提示，直到处理完毕。

### 进入业务数据维护

1. 第三张卡片是「业务数据维护」，标注「关税与禁运数据」，说明为「数据版本、检查更新和更新历史由独立页面管理」。
2. 点击右侧的「打开数据维护」按钮，跳转到数据维护页面，关税与 Alta 禁运数据库的检查更新都在那边操作。

### 查看版本信息

1. 最下方是「关于 Liao Tools」卡片，显示应用图标、名称和当前版本号（形如「版本 0.0.29」）。
2. 点击右侧的「GitHub 仓库」按钮，会在浏览器中打开项目的 GitHub 仓库页面，可以查看源码与发布记录。

## 小技巧

- 顶栏右侧的月亮／太阳图标按钮可以在浅色、深色之间一键切换，效果等同于在「显示模式」里改选对应项。
- 不想手动管深浅色，就把「显示模式」留在「跟随系统」，白天浅色、晚上深色自动切换。
- 侧边栏底部有常驻的「应用更新」入口，出现绿点即表示发现新版本，点进去可完成下载和安装。
- 「应用更新」卡只管应用程序本身；关税、禁运数据的更新入口是「业务数据维护」卡里的「打开数据维护」，两者互不相干。

## 常见问题

**问：打开了「自动检查应用更新」，为什么没有自动安装新版本？**

答：这个开关只负责在应用启动时按间隔检查并提示，下载与安装需要你自己在「检查应用版本」弹窗里确认，应用不会替你自动安装。

**问：关税或 Alta 禁运数据要怎么更新？**

答：不在本页操作。点击「业务数据维护」卡中的「打开数据维护」进入对应页面，在那里检查和更新业务数据库，详见[数据维护](/guide/data-maintenance)。

**问：「关于 Liao Tools」里的版本号显示「读取中…」或「无法读取」怎么办？**

答：「读取中…」是正常加载过程，稍等即可；如果一直显示「无法读取」，重启应用通常可以恢复。
