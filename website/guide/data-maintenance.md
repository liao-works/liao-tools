# 数据维护

「数据维护」集中管理两套相互独立的本地数据库：英国 / 北爱关税税率和 Alta 禁运清单。在这里可以查看本地数据版本、检查数据来源有没有新版本、执行更新，并回看每一次更新留下的真实记录。适用场景：查询结果可疑时先确认数据版本；应用提示「远程数据库已更新」时来这里升级数据。

## 在哪里找到入口

- 打开应用后，点击左侧边栏底部「管理」分组中的「数据维护」。
- 当远程数据源有新版本时，「数据维护」入口会显示一个绿点，鼠标悬停提示「远程数据库已更新，需要更新数据」。
- 也可以在「偏好设置」页的「业务数据维护」卡片中点击「打开数据维护」按钮进入。
- 注意：按 Ctrl K 打开的搜索框中虽然也有「数据维护」一项，但选中后会跳到关税查询页的「数据更新与审核」页签，并不会进入本页；请以后两种入口为准。
- 页面支持 URL 参数直达：`/data-maintenance?module=alta` 会直接打开「Alta 禁运」页签。

## 页面布局

页面从上到下依次是：标题与说明、一条警示条、模块页签和右上操作按钮。

警示条写明：**更新不等于已完成税率核验。**本地安装、远程可用、核验状态和审核候选是不同概念；尤其 NI 条件数据不能因为下载或审计通过而直接当作确定税率。

页签有两个：「英国 / 北爱关税」和「Alta 禁运」，分别复用关税查询页和 Alta 查询页中的数据维护面板。右上角有两个按钮：「更新历史」和「返回业务查询」。

## 逐步操作

### 一、英国 / 北爱关税页签

打开页面时默认停在「英国 / 北爱关税」页签。页签顶部有一张「关税数据」说明卡：正式数据库更新继续使用受保护的下载命令；NI Other 审核与影子预览仅供核对，不会自动升格为正式税率。

1. **查看本地版本。**「本地版本」卡片显示当前数据的版本号、记录数和更新日期。打开页面时会自动读取本地元数据，不需要手动刷新。
2. **点击「检查更新」。**按钮在「更新操作」卡片中，点击后变为「检查中...」。检查完成后：
   - 发现新版本时，弹出提示「发现新版本」，右侧出现「远程版本」卡片（显示远程版本号、记录数、发布日期，标题为「🎉 有可用更新」），「立即更新」按钮变为可点击；
   - 已是最新时，弹出提示「已是最新版本」，远程版本卡片显示「✅ 已是最新版本」；
   - 无法联网时，弹出提示「无法联网检查最新版本」，页面出现「当前无法获取远程版本。本地数据仍可查询，但无法确认是不是最新税率。」的说明。
3. **点击「立即更新」下载新数据。**该按钮在检查更新发现新版本之前是置灰的。点击后按钮变为「下载中...」，下方出现进度条，显示百分比和已下载 / 总大小（如 `12.34 MB / 45.67 MB`）。完成后弹出「税率数据更新已完成」，「本地版本」卡片刷新为新版本号。更新任务在后台执行，中途切换到其他页面不会打断，回到本页可继续看到进度。
4. **查看「更新日志」。**检查更新成功后，如果远程数据源附带更新说明，页面会出现「更新日志」卡片（说明文字为「最近的数据更新记录」），逐条列出每次更新的内容说明和日期。
5. **查看「更新历史」。**点击右上角（或「更新操作」卡片内）的「更新历史」按钮，弹出标题为「更新历史（关税）」的对话框，列出本机的更新记录：每条显示模块、更新类型（全量更新 / 单行更新）、目标版本号、时间和变更条数。
6. **查看某次更新的变更明细。**在历史列表中点击任意一条记录，会弹出「关税变更明细」对话框：面包屑显示模块名和版本区间（如 `关税 → v2026.09.01 → v2026.09.12 → 变更明细`），下方按商品编码分组，每个字段变动用「新增」「删除」「修改」标签标出，并显示旧值到新值的对比。点击「返回列表」回到历史列表，关闭对话框即退出。
7. **查看「数据更新日志」。**页签底部有一张「数据更新日志」卡片，记录本机最近 50 条检查 / 下载 / 安装 / 失败事件流水（如「检查更新：发现新版本」「下载并校验完成」「已安装新数据包」）。点击卡片右上角的刷新图标可重新加载。逐字段的税率变化明细以「更新历史」对话框为准。
8. **查看「操作日志」。**执行过检查或下载后，页面底部会出现「操作日志」卡片，以等宽字体逐行显示带时间戳的操作过程，内容超出时卡片内部滚动并自动停在最新一条。

### 二、审核与影子预览（高级操作）

在关税页签中，点击「审核与影子预览（高级操作 · 不写入正式税率库）」展开折叠区。这里的三张卡片都只读取外部数据包做核对，不会写入正式税率库：

1. **「NI Other · 证据审核」：**点击「选择 NI 审核报告 JSON」，在文件选择框中选中采集端生成的 `xi-review-gate.json`。读取后显示报告日期、样本数、涉及的 HS 章节数、覆盖门槛，以及「证据覆盖要求已达到，仍需业务确认」或「样本不足，不能进入业务核验」的结论和待人工复核条数。每条待复核编码旁有「核对官方页面」按钮，点击会在浏览器打开英国官方贸易关税网站上该 XI 商品的页面。
2. **「第三国税率 · 独立预览」：**点击「选择影子预览 ZIP」导入采集端生成的 `target-duty-preview.zip`，导入成功后提示「预览包已隔离导入」，并显示版本、数据日期和商品编码数、GB 唯一税率、条件/歧义、NI 未核验四项统计。在输入框填入完整 10 位商品编码，点击「查询预览」，会并排显示「当前生产数据库」与「官方 GB 目标税率预览（不能直接申报）」的对比结果。
3. **「签名审计包验证（非生产）」：**仅当应用编译时内置了可信签名公钥才会出现这张卡片。点击「选择签名审计 ZIP 进行验证」，选择 Ed25519 签名审计包后显示签名状态、密钥、版本和数据条数。即使验证通过，也不会安装到正式税率数据库。

### 三、Alta 禁运页签

1. 点击页签栏中的「Alta 禁运」，切换到禁运清单维护面板。页签顶部的「禁运清单」说明卡提示：查询时「未命中」仅表示当前清单未匹配，不能证明商品全面合规。
2. **查看本地状态。**「本地禁运数据库」卡片自动读取并显示三项数据：本地记录数、最后更新时间和数据库大小（MB）。读取失败时显示红色错误条，可点击「重试读取」。
3. **点击「更新禁运清单」。**按钮点击后变为「正在更新清单」，由原有 Alta 数据命令执行更新；完成后弹出「禁运清单更新完成」，卡片自动重新读取本地记录数和更新时间。失败时弹出「禁运清单更新失败」并显示原因。
4. **点击「刷新本地状态」。**不执行更新，只重新读取本地数据库的记录数、更新时间和大小。
5. **查看「更新历史」。**点击卡片中的「更新历史」按钮，弹出的对话框标题为「更新历史（禁运）」，操作方式与关税页签相同：点击一条记录查看「禁运变更明细」。
6. **查看「本次操作日志」。**执行过更新后，卡片下方出现「本次操作日志 · N 条」折叠项，点击展开可查看逐行日志。

### 四、返回业务查询

点击右上角的「返回业务查询」按钮，会跳回与当前页签对应的查询页面：在「英国 / 北爱关税」页签下跳到关税查询，在「Alta 禁运」页签下跳到 Alta 禁运查询。

## 小技巧

- 更新任务的状态保存在全局：下载进行到一半可以切去别的功能页干活，回来看进度即可，不会被中断。
- 「数据更新日志」（本机操作流水）和「更新历史」（逐字段变更明细）是两回事：想知道「我做过哪些操作」看前者，想知道「某个编码的税率具体改了什么」看后者。
- 数据更新完成后，侧边栏「数据维护」入口上的绿点会自动消失。
- 打开页面只读取本地版本，不会自动联网检查；想确认远程是否有新版本，需要手动点「检查更新」。

## 常见问题

**问：为什么「立即更新」按钮是灰的？**

答：「立即更新」只有在「检查更新」发现远程有新版本后才会启用。先点「检查更新」，确认有可用更新后即可点击下载。

**问：检查更新时提示「无法联网检查最新版本」怎么办？**

答：表示当前无法连接远程数据源。本地已安装的数据仍可正常离线查询，只是无法确认是不是最新版本；恢复网络后再检查一次即可。

**问：更新历史列表显示「暂无更新记录」正常吗？**

答：正常。历史记录从本机第一次成功更新后才开始累积，全新安装的应用可能还没有记录。

**问：Alta 页签显示「本地清单没有记录」怎么办？**

答：页面会提示「在获得清单前，不能把查询未命中理解为没有限制」。此时应先点击「更新禁运清单」获取清单数据，再去做禁运筛查。

**问：影子预览里的税率能直接用来申报吗？**

答：不能。页面明确标注预览包「未经生产签名」「不能直接申报」「不会修改正式 tariffs.db」，它只用于与正式库做人工核对。
