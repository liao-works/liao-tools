# 使用统计

使用统计把本机各工具的查询次数、查询数据量、处理数据量与处理时长汇总在一页里，可按近 7 天（周视图）或近 30 天（月视图）查看。统计在你使用各工具时自动进行，不需要手动开启；数据只保存在本机，不会上传。

## 在哪里找到入口

打开应用后，点击左侧边栏「管理」分组中的「使用统计」即可进入，对应页面地址为 `/usage`。

进入后页面从上到下依次是：统计范围切换与「刷新」按钮、四张汇总卡、「按日趋势」柱状图、「工具明细」表。

## 逐步操作

1. 在页面左上角的统计范围切换里点「周视图（近 7 天）」或「月视图（近 30 天）」。点击后汇总卡、趋势图和明细表会立即按所选范围重新加载，应用默认打开周视图。两个范围都包含今天在内。
2. 点右上角的「刷新」按钮可重新读取当前范围的统计。读取期间按钮图标会变成旋转样式并暂时不可点击；页面首次还在加载时会显示「正在读取统计数据…」。
3. 看四张汇总卡，它们是当前范围内的总量：「查询次数」是各工具完成的查询总数；「查询数据量」是查询过的编码、单号等条目数；「处理数据量」是处理过的行数或文件数；「处理时长」是各操作耗时之和，按「x ms」「x.x 秒」「x 分 x 秒」显示。次数和数据量超过一千时会带千分位（如 1,050）。
4. 在「按日趋势」卡片里点「查询次数 / 查询数据量 / 处理数据量 / 处理时长」四个胶囊按钮之一，柱状图会切换为该指标的逐日柱子，当前选中的胶囊高亮显示。默认显示「查询次数」。
5. 把鼠标悬停在某根柱子上，会显示该日的完整日期和数值（如「2026-10-24：105」，处理时长指标则显示成「2 分 5 秒」这样的格式）。周视图的横轴标签是「10/18 周日」这样的「月/日 + 星期」，月视图只有「10/18」这样的「月/日」。
6. 在「工具明细」表里按工具查看使用情况，表头为「工具 / 查询次数 / 查询数据量 / 处理数据量 / 处理时长」。工具名列显示中文名称，如「关税查询」「Alta 禁运查询」「Excel 数据拆分」「文本处理」等。

## 小技巧

- 汇总卡与「工具明细」表都是所选范围（近 7 / 30 天）的累计值，页面不提供按天查看单个工具的用量；想知道某天的整体使用情况，用「按日趋势」看当天的柱子即可。
- 柱状图里数值为 0 的日子显示为浅灰色矮柱，一眼就能看出哪天完全没用过。
- 月视图有 30 根柱子，窗口较窄时图表区域可以左右滚动查看全部日期。
- 刚在别的工具里完成一次查询后回到本页，点「刷新」即可拿到最新数据（切换周 / 月视图时也会自动重新加载）。

## 常见问题

**问：明细表里提示「当前范围内还没有使用记录；去任意工具页查询或处理一次数据后再来看这里。」**

答：说明所选范围（近 7 天或近 30 天）内没有任何使用记录。去任意工具页完成一次查询或处理，再回到本页点「刷新」即可看到。

**问：为什么有些功能（如 Todo 清单、系统工具、偏好设置）没有出现在明细里？**

答：使用统计只记录涉及查询或数据处理的工具，包括关税查询、Alta 禁运查询、Amazon 商品查询、体积 / 计费重计算、轨迹查询、船司查询、汇率查询、Excel 数据拆分、翻译、文本处理和 UPS / DPD，与「工具明细」表中显示的名称一致；日常效率与应用管理类功能不计入。

**问：统计数据会上传或同步到别处吗？**

答：不会。每次使用事件只写入本机应用数据目录下的 `usage_stats.db`（SQLite）文件，记录会一直保留；卸载并重装应用后统计仍在，只有删除该文件后统计才从零开始。

**问：页面显示「读取使用统计失败：……」怎么办？**

答：这是读取本地统计文件出错时的提示。先点「刷新」重试；若持续失败，检查应用数据目录是否可写（例如是否被杀毒软件或权限设置限制）。
