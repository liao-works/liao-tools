# 翻译

「翻译」是面向外贸邮件的 AI 文本工具，提供「翻译」「润色」「解释」三种模式：把一段文字译成目标语言、改写得更得体，或者解读对方邮件的语气与意图。结果逐字流式输出，每次运行自动存入本机历史。使用前需要配置一次模型供应商（DeepSeek / Gemini / 自定义接口），配置保存在本机。

## 在哪里找到入口

- 打开应用后，点击左侧边栏「效率工具」分组里的「翻译」。
- 也可以从[工作台](/guide/home)右栏的「最近翻译」卡片进入：点卡片右上角的「去翻译」，或直接点某条记录——会带着原文与译文回到翻译页。

## 第一次使用：配置供应商

翻译由在线大模型完成，首次使用先点页面右上角的「供应商」按钮，弹出「供应商配置」窗口（窗口说明：选择一家服务商并填入 API Key，配置保存在本机）。

1. 在「DeepSeek」「Gemini」「自定义」三张卡片中选一家；已配置过的供应商卡片上会带 ✓。
2. 选「DeepSeek」：窗口内会提示「注册后在「API Keys」页创建，Key 以 sk- 开头。国内直连可用。」，点「前往申请 API Key ↗」会在系统浏览器打开申请页；「模型」下拉可选 deepseek-chat、deepseek-reasoner，也可选「自定义…」手填模型名。
3. 选「Gemini」：提示「Google AI Studio 创建 Key。国内使用需要开启系统代理。」，模型可选 gemini-2.5-flash、gemini-2.5-pro。
4. 选「自定义」：需要填写「Base URL（必填，以 /v1 结尾）」——即 OpenAI 兼容接口地址，再手填模型名（占位示例 gpt-4o-mini）。
5. 在「API Key」密码框粘贴 Key。该供应商保存过 Key 时，标签会带上脱敏结果（只保留 Key 末 4 位，前面至多 3 个星号，不保留 sk- 前缀，如「API Key（已保存 ***abcd）」），输入框提示「留空则不修改」——Key 不回显明文，留空保存即保持不变。
6. 点「保存并启用」。「模型」必填，首次启用某家供应商时必须填入 Key，条件不满足时按钮不可点。

之后随时从同一入口换供应商或改模型；换回一家已配置过的供应商不需要重新填 Key。

## 逐步操作

页面分上下两块：顶部工具条（模式、语言、语气，右侧是「自定义提示词」「历史」「供应商」按钮），下方左右双栏——左栏输入原文、右栏输出结果。

![翻译页整体布局：上方为模式、语言、语气工具条与「自定义提示词 / 历史 / 供应商」按钮，下方为左右双栏](/images/translate/01-overview.png)

1. 在工具条左侧的按钮组选择模式：「翻译」「润色」「解释」，默认「翻译」。切换模式会清空右栏输出。
2. 「翻译」模式下会出现「自动检测 → 自动（互译）」两个语言下拉。源语言默认「自动检测」，输入内容后下拉框会实时回显识别结果（如「自动检测（中文）」）；目标语言默认「自动（互译）」——中文译为英语、其他语言译为中文，也可以手动选定「中文 / 英语 / 日语 / 韩语 / 德语 / 法语 / 西班牙语 / 俄语」之一。
3. 当自动识别出的源语言与目标语言相同（比如中文原文配了中文目标），工具条下方会出现提示「识别到原文已是中文，继续运行会原样返回」，并附「改为英语」按钮，点一下即自动换向。
4. 选择语气三档：「自然商务」「轻松随和」「严谨正式」（翻译、润色模式可用）。想额外交代背景就点旁边的「补充」，在弹出的「补充说明」窗口写一句给模型的说明（占位示例：对方是合作多年的老客户，语气可以随意些），点「保存」后按钮变为高亮的「已补充」；窗口内也可直接 Ctrl+Enter 保存。之后再次打开、留空保存即清除。
5. 在左栏粘贴或输入原文，左下角显示字符数；超过 8000 字符会提示「文本较长，响应可能较慢」。

![已粘贴中文原文：源语言回显「自动检测（中文）」，目标回显「自动（→英语）」，左下角显示字符数](/images/translate/02-filled.png)

6. 点右栏下方的「运行（Ctrl+Enter）」按钮，或直接按 Ctrl+Enter，译文逐字出现在右栏。无输入或供应商未配置时运行按钮不可点；未配置供应商时右栏中央会显示「三步开始使用」引导和「去配置供应商」按钮。
7. 运行中「运行」按钮变为红色「停止」，点它（或按 Esc）即可中止。
8. 运行出错时右栏顶部显示红色错误原因并注明「（可重试）」，同时弹出「翻译失败」通知；按提示处理后重新运行即可。
9. 完成后点右下角「复制」把结果复制到剪贴板，按钮会短暂变为「已复制」。

### 润色模式

切到「润色」后语言下拉隐藏（只改写当前文字，不做翻译），语气三档照常生效，适合把中文邮件改得更得体、更正式；右栏空态提示相应变为「改写后的文本会出现在这里」。

### 解释模式

切到「解释」后语气选择也隐藏，左栏占位提示变为「粘贴要解读的邮件…（Ctrl+Enter 运行）」。把对方整封邮件贴进左栏运行，右栏给出该邮件语气与意图的中文解读。

### 自定义提示词

点右上角「自定义提示词」按钮，页面会出现一个文本框：输入完整的系统提示词后，运行时将完全替换内置提示词，角色、语气、输出规则全部由你定义；留空则仍使用内置提示词。开启期间，语气三档与「补充」按钮会隐藏。再点一次「自定义提示词」即可关闭。开关与内容只在本页有效，离开页面后会重置。

## 历史记录

- 点右上角「历史」打开「翻译历史」窗口，按时间倒序列出记录，每条显示时间、模式（翻译 / 润色 / 解释）、语气、供应商 / 模型以及原文、结果的摘要，最多加载最近 100 条。
- 点击某条记录：会切回该条使用的模式、把原文填回左栏，该条结果也会一并显示在右栏，并关闭窗口，方便在此基础上修改后重新运行。
- 每条记录首行右侧（时间、模式、语气之后的「供应商 / 模型」旁）有删除图标，点它可删除单条；点窗口标题旁的「清空」清空全部历史，完成后提示「历史已清空 共删除 n 条」。

## 小技巧

- 中英互译保持两个「自动」即可，应用会按输入语言自动换向，不用每次改方向。
- 「补充」里的说明会叠加在所选语气之后，每次运行都生效；不需要时打开窗口留空保存。
- 有固定输出要求的场景（比如每次都要两版备选译文），把要求写成完整的系统提示词，用「自定义提示词」开启后当页反复运行。
- 超长邮件拆成几段分别运行，响应更快。

## 常见问题

**问：右栏显示「三步开始使用」，运行按钮是灰的？**

答：还没有配置供应商。点右上角「供应商」或右栏里的「去配置供应商」，按「第一次使用：配置供应商」的步骤填入 API Key。

**问：提示「API Key 无效或已过期，请在供应商配置中检查。」？**

答：Key 填错、已删除或已过期。到「供应商配置」里重新粘贴正确的 Key 并「保存并启用」。

**问：提示「网络连接失败。Gemini 需要系统代理，请确认代理已开启；DeepSeek 请检查网络。」？**

答：连不上当前供应商。用 Gemini 需要先开启系统代理；用 DeepSeek 则检查本机网络后重试。

**问：提示「请求过于频繁或额度不足，请稍后再试。」？**

答：供应商限流或账户额度用尽，稍后再试，或到供应商控制台检查额度、更换模型。

**问：「识别到原文已是××，继续运行会原样返回」是怎么回事？**

答：源语言「自动检测」识别出的语言与目标语言相同（如中文原文配了中文目标），直接运行只会原样返回。点提示里的「改为英语」或「改为中文」一键换向，或在下拉中手动改目标语言。

## 相关功能

- [工作台](/guide/home)：右栏「最近翻译」卡片列出最近 5 条记录，点击可带着原文与译文回到翻译页继续编辑。
- [偏好设置](/guide/settings)：应用外观（浅色 / 深色 / 跟随系统）等全局偏好在偏好设置里调整，翻译页外观随全局主题一起变化；翻译的供应商与 Key 配置则独立保存在本机。
