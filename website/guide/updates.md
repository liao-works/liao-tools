# 应用更新

Liao Tools 不会在后台悄悄替你升级。「应用更新」页负责把 GitHub 上的最新正式版摆到你面前：显示当前版本与最新版本、列出更新说明，下载安装包后由系统安装程序完成升级，每一步都由你点击确认。

## 在哪里找到入口

- 侧边栏底部「管理」分组中的「应用更新」。发现新版本时，这一项右侧会出现绿点，悬停提示「发现新版本 vX.Y.Z，需要更新应用」。
- 侧边栏最底部还有一条固定的「应用更新」快捷入口，点击进入同一页面。
- 按 `Ctrl K` 打开命令面板，输入「应用更新」回车。

页面地址为 `/updates`，可以直接跳转。

## 逐步操作

### 检查是否有新版本

1. 进入「应用更新」页，页头说明为「了解最新桌面版本、查看更新内容并由系统安装程序完成升级。」
2. 页面中间是「检查 Liao Tools 更新」卡片，说明写着「从正式 GitHub Release 获取适用于当前系统的版本信息和安装包」，点击卡片里的「检查更新」按钮。

![应用更新页面：「检查 Liao Tools 更新」卡片内有「检查更新」按钮，下方并排「下载来源与校验」「用户确认安装」两张说明卡](/images/updates/01-overview.png)

3. 会弹出「检查更新」对话框并自动开始联网检查（无需再点一次），检查期间显示「正在检查更新...」。
4. 检查完成后，对话框列出当前版本、最新版本、发布时间和文件大小：
   - 已是最新版本时，提示「您使用的已是最新版本」。
   - 有新版本时，提示「发现新版本！」，并附「更新说明」——该版本的发布内容，可在框内滚动查看。
5. 想再查一次点右下角的「重新检查」；看完点「关闭」退出对话框。

### 下载并安装新版本

1. 在「发现新版本！」提示下，点击「立即更新」，开始从 GitHub Release 下载适用于当前系统的安装包（Windows x64 为 `_x64-setup.exe` 或 `_x64_en-US.msi`）。
2. 下载期间显示进度条、已下载 / 总大小和百分比，并提示「下载正在执行，当前版本未提供取消命令。」；此时对话框不能关闭，「关闭」按钮会变成灰色的「下载中...」。
3. 下载完成后，提示变为「下载完成，点击下方按钮安装」，原来的「立即更新」按钮变为「安装更新」。
4. 点击「安装更新」，对话框显示「正在启动安装程序...」，由系统安装程序完成安装；随后对话框内提示「已提交安装命令；请根据系统安装程序完成操作。」，按钮变为不可点的「安装命令已提交」。
5. 在 Windows 上安装程序会在后台静默执行，完成后应用弹出「更新完成」对话框，显示「已成功更新到版本 X.X.X」——点「立即重启」马上以新版本运行，或点「稍后手动重启」之后自己重启。
6. 在 macOS 上应用只会打开 dmg 安装镜像，安装是否完成以你在安装窗口里的操作为准（把新版本拖入「应用程序」）；应用不会把「打开了安装程序」当成「已经装好」。

> 本节的逐步说明以 Windows 与 macOS 为准：官方 Release 目前只发布 Windows 与 macOS（Apple Silicon）安装包，不提供 Linux 安装包。Linux 上「检查更新」仍能正常看到当前版本、最新版本和更新说明，但点「立即更新」会提示「未找到适用于当前平台的安装包」，请点错误提示下方的「打开官方版本下载页」手动下载。

### 管理自动检查

1. 「检查更新」对话框底部有「启动时自动检查更新（每24小时）」复选框，默认勾选。
2. 勾选时，应用启动约 3 秒后会检查一次，运行期间每小时也会再试；但距上次检查不足 24 小时的检查会直接跳过。
3. 自动检查发现新版本时，会弹出「检查更新」对话框（描述为「自动检查发现新版本」），同一次运行中同一版本只弹一次；侧边栏「应用更新」入口同时出现绿点。
4. 取消勾选会立即保存，之后只在你手动点「检查更新」时才联网检查。这个开关与[偏好设置](/guide/settings)页「应用更新」卡里的「自动检查应用更新」开关是同一份设置，改哪边都行。
5. 无论自动还是手动检查，只要确认过有新版本，绿点就会留在侧边栏入口上，直到某次检查确认已是最新版本才消失。

### 检查失败时

1. 网络不通或 GitHub 接口受限时，对话框内会出现红色错误提示，例如请求次数受限时提示「GitHub 更新接口请求次数受限（HTTP 403/429）。请稍后重试，或打开官方发布页面手动下载安装。」。
2. 错误提示下方有「打开官方版本下载页」按钮，点击会在浏览器打开 GitHub Releases 最新版页面，可以手动下载安装包。

## 小技巧

- 页面上「下载来源与校验」「用户确认安装」两张说明卡概括了这个功能的工作方式：安装包只来自正式 GitHub Release 并按当前系统挑选对应文件；下载失败和安装程序启动状态都会如实提示，不夸大安装进度。
- 下载过程中对话框关不掉、也没有取消按钮，属于预期行为；下载一般只需十几秒到几分钟，取决于网速。
- 手动检查的结果同样会更新侧边栏绿点：检查到新版本绿点亮起，确认已最新后绿点消失。
- [偏好设置](/guide/settings)页也有一个「检查应用版本」按钮，弹出的就是本页这个「检查更新」对话框。

## 常见问题

**问：检查更新一直失败怎么办？**

答：先看错误提示。网络问题请检查连接后点「重新检查」；提示请求次数受限（HTTP 403/429）是 GitHub 对匿名请求的限制，等一段时间再试，或点「打开官方版本下载页」手动下载安装包。

**问：点了「安装更新」好像没反应？**

答：Windows 上安装程序在后台静默运行，对话框会停在「正在启动安装程序...」，安装完成后才弹出「更新完成」，请耐心等待；macOS 上请留意弹出的 dmg 窗口，按提示完成拖入安装。

**问：Linux 上能按这一页的步骤更新吗？**

答：「检查更新」不受影响，能正常看到最新版本和更新说明；但官方 Release 目前不提供 Linux 安装包，点「立即更新」会提示「未找到适用于当前平台的安装包」。请点「打开官方版本下载页」在浏览器里手动下载，并留意后续版本对 Linux 安装包的支持。

**问：自动检查的弹窗多久出现一次？**

答：勾选「启动时自动检查更新（每24小时）」时，距上次成功检查满 24 小时后，应用会在启动约 3 秒后联网检查一次（运行期间每小时到点也会再试，同样受 24 小时间隔约束）；查到新版本才弹窗，且同一次运行中同一版本只弹一次。24 小时内重启应用不会重新检查、也不会弹窗，升级到新版本后同理。想完全关闭自动检查，取消勾选该复选框，或在[偏好设置](/guide/settings)里关掉「自动检查应用更新」。

**问：关税或 Alta 禁运数据的更新在哪里？**

答：不在本页。「应用更新」只管 Liao Tools 程序本身；业务数据库的版本检查与更新在[数据维护](/guide/data-maintenance)页操作。
